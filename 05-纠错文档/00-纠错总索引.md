## 一、使用规则

1. **随时记录**：每次做题、测验暴露出的错误，立即登记到"错误总表"。
2. **编号管理**：每个错误分配唯一编号 `ERR-XXX`，方便追踪。
3. **检验升级**：按"间隔复习检验方案"定期检验，通过则标记 ✅。
4. **升降级规则：**
   - 连续 **2 次** 检验通过 → 状态升级为 ✅ 已掌握
   - 已掌握后**再次犯错** → 状态降级为 🔄 复发，重新走检验周期

| 状态 | 含义 |
|------|------|
| 🔴 新发现 | 刚记录，还没检验过 |
| 🟡 复习中 | 已检验 1 次以上，尚未完全掌握 |
| 🔄 复发 | 已掌握过，但又犯错了 |
| ✅ 已掌握 | 连续 2 次检验通过 |

## 三、错误详细卡片

> 每张卡片包含：错误写法 → 正确写法 → 原因 → 记忆口诀。

<!-- 新错误按下方模板追加 -->

### ERR-001 · 方法名拼写 containkey → containsKey

- ❌ **错误写法：** `map.containkey(prefix - k)`
- ✅ **正确写法：** `map.containsKey(prefix - k)`
- 📖 **为什么错：** HashMap 判断键是否存在的方法是 `containsKey`（contains + Key，K 大写），没有 `containkey`，也没有 `contains`（那是 HashSet 的方法）。
- 🧠 **口诀：** 查键认准 **containsKey**：带 s、K 大写。

### ERR-002 · return 写到方法外

- ❌ **错误写法：** `return count;` 写在方法右花括号 `}` 之后
- ✅ **正确写法：** `return` 写在 for 循环结束之后、方法结束 `}` 之前
- 📖 **为什么错：** return 必须属于某个方法，写在方法外编译器找不到所属方法。根因是花括号层级没对齐。
- 🧠 **口诀：** return 回家要进门（在方法的 `{}` 里面）。

### ERR-003 · 覆盖 vs 累加（map 签到）

- ❌ **错误写法：** `map.put(prefix, 1)` —— 每次把次数设成 1，覆盖掉历史次数
- ✅ **正确写法：** `map.put(prefix, map.getOrDefault(prefix, 0) + 1)` —— 在原次数上 +1
- 📖 **为什么错：** 这里要统计"前缀和出现几次"，同一个前缀和可能多次出现，必须累加；用 1 覆盖会丢失次数。
- 🧠 **口诀：** 签到本上要**累加**，不是重写；`getOrDefault` 先查再加。

### ERR-004 · if 后缺花括号

- ❌ **危险写法：** `if (条件)` 下一行语句没加 `{}`
- ✅ **安全写法：** `if (条件) { ... }` 哪怕只有一行
- 📖 **为什么危险：** 没花括号时 if 只管紧挨着的下一行；以后往里加代码容易误以为都在 if 里。
- 🧠 **口诀：** if 永远带大括号。

## 四、间隔复习检验方案 ⭐

### 4.1 检验时间点（艾宾浩斯遗忘曲线改良版）

每个新错误发现后，在以下 **5 个时间点** 检验：

| 检验次数 | 时间点 | 对应学习日 | 检验方式 |
|---------|--------|-----------|---------|
| 第 1 次 | 发现当天 | Day 1 睡前 | 🗣️ 口头复述错误原因（不看文档） |
| 第 2 次 | 次日 | Day 2 开始前 | ✍️ 判断/填空题（5 分钟小测） |
| 第 3 次 | +3 天 | Day 4 开始前 | ✅ 判断题（快速识别对错） |
| 第 4 次 | +7 天 | Day 8 开始前 | 💻 手写正确代码 |
| 第 5 次 | +14 天 | Day 15（结束后） | 🏆 综合测验（混入新错误一起考） |

> **说明：** 时间点与刷题计划中的"间隔复习日"对齐（Day 3 复习 Day 1、Day 5 复习 Day 2...），确保不额外增加负担。

### 4.2 检验流程

每次检验由 **AI 教练** 在对应学习日开始时发起：

```
Step 1: 从"错误总表"中挑出"到期"的错误（状态不是 ✅）
Step 2: 出 3-5 道对应题型的小题（判断/填空/写代码）
Step 3: 学员作答
Step 4: 批改并更新状态：
        - 全对 → 该错误本轮通过，记录检验结果
        - 有错 → 该错误本轮未通过，重新计时（回到第 2 次）
Step 5: 更新"检验记录表"和"错误总表"状态
```
